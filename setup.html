TLP sign-in setup

One-time page for the security upgrade. Run step 1 and step 2 before uploading the new index.html and dashboard.html. Run step 3 the next day. Delete this file from GitHub when you're done.

Admin check

Log in with your admin username and your current PIN.

Step 1 — Create sign-in accounts

Creates a Firebase sign-in for every person in the Users list. Their current 4-digit PIN keeps working; the app asks each person to choose a new 6-digit PIN the first time they log in. Safe to run more than once.

Step 2 — Move lockbox/alarm codes, owners and check-in notes into the database

Copies them from the current live index.html into Firestore, where only signed-in staff can read them. Must run before the new index.html is uploaded (the new one no longer contains them). Safe to run more than once.

Step 3 — Remove the old 4-digit PINs from the database (the next day)

Only after the new apps and rules have worked for a day. After this, going back to the old files is no longer possible. For this step, log in above with your new 6-digit PIN.
